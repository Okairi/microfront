### 💳 Datos de Prueba

Para realizar pruebas en el entorno de desarrollo, puedes utilizar los siguientes datos de ejemplo:

* **Tarjeta:** `4242424242424242`
* **MM/AA:** Cualquier número válido (ej. `15/27`, `10/28`)
* **CVC:** Cualquier número (ej. `123`, `444`)
* **Correo electrónico:** Cualquier correo (ej. `test@gmail.com`, `usuario@hotmail.com`)
* **Nombre:** Cualquier nombre (ej. `Test`, `Usuario`)

> **Importante:** Estos datos son únicamente para entornos de pruebas (Sandbox/Staging). No utilices información de tarjetas reales.
